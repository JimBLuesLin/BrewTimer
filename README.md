# ☕ 咖啡冲煮助手 (Coffee Brewing Assistant)

> **一款面向手冲与冷萃爱好者的精品微信小程序计时工具**
>
> 基于原生微信小程序框架开发，专为咖啡师与深度玩家打造。它不仅是一个计时器，更是一个融合了世界冠军级数据参数、智能联动计算与原生教学视频的“冲煮导师”。

---

## 🚀 核心功能特性

1. **参数高度定制与智能联动**
   - 支持 **手冲 (Pour Over)** 与 **冷萃 (Cold Brew)** 双模式切换。
   - 可自定义配置咖啡豆品种、烘焙程度（浅/中/深）及研磨度（极细/细/中/粗/极粗）。
   - 默认推荐 **15g 黄金粉量**（支持动态调整），系统根据冲煮方式与烘焙度**自动联动推算**最科学的建议水温、粉水比及目标总水量。

2. **大师配方预设与参数强锁定 (Champion Presets)**
   - 内置三位世界级咖啡大师的经典冲煮模型，支持一键套用并自动按当前粉量等比例换算：
     - **粕谷哲 (Tetsu Kasuya) · 四六法**：自动联动并硬锁定为**粗研磨**、92°C水温、1:15比例，完美划分5段注水节奏。
     - **James Hoffmann · V60极致法**：自动联动并硬锁定为**中细研磨**、99°C沸水直冲、1:16.6比例，配合湿润摇滤提示。
     - **Scott Rao · 高萃取两段法**：自动联动并硬锁定为**中度研磨**、95°C水温、1:16比例，引入 Rao Spin 收尾提示。
   - 选中大师配方后，水温、研磨度、粉水比选择器自动进入**带 🔒 图标的禁用状态 (Disabled)**，确保配方的物理严谨性。

3. **烘焙度软关联预警系统 (Soft Warning)**
   - 保持品种与烘焙度开放可选。若用户在大师模式（如 Hoffmann 或 Rao）下误选了“深度烘焙”，系统会自动触发高亮预警提示框：`⚠️ 该大师手法追求高萃取率，搭配深烘豆极易产生焦苦味，建议使用浅/中烘焙咖啡豆。`

4. **沉浸式原生视频内嵌**
   - 拒绝打破冲煮专注感的跨小程序跳转！页面原生内嵌微信 `<video>` 组件，支持在大师卡片下方直接异步加载高清原版教学视频，实现边看视频边冲煮的丝滑操作。

5. **精准分段计时与盲操震动提醒**
   - 计时视图采用大字号极简设计。根据所选手法（三段式/一刀流/十段法/大师法）自动动态渲染当前阶段、时间轴范围、目标阶段注水量及核心动作提示。
   - 引入高效的阶段状态机检测，在进入全新注水阶段的瞬间触发 `wx.vibrateShort({ type: 'heavy' })` **干脆利落的强震动反馈**，无需频繁死盯屏幕。

6. **极致移动端体验优化**
   - **防阻断悬浮布局**：采用 `position: fixed` 将“开始冲煮”主操作按钮抽离至底部悬浮容器（`.action-footer`），配合奶油白向透明的向上渐变底板。即使参数项再多，核心 CTA 按钮也永远触手可及。
   - **全面屏自适应**：利用 `env(safe-area-inset-bottom)` 动态计算全面屏与刘海屏底部的安全距离。
   - **防息屏机制**：冲煮开始后自动开启 `wx.setKeepScreenOn` 锁死屏幕常亮，结束或退出后自动释放。

## 🛠️ 技术栈与依赖

| 层面 | 技术方案 / API | 说明 |
| :--- | :--- | :--- |
| **小程序框架** | 原生微信小程序 (glass-easel) | 官方高性能现代化组件框架 |
| **核心语言** | TypeScript + WXML + WXSS | 强类型支撑，业务逻辑安全严密 |
| **核心 API** | `wx.vibrateShort` | 阶段切换时的硬件震动反馈 |
| | `wx.setKeepScreenOn` | 冲煮全过程手机屏幕常亮控制 |
| | `setInterval` / `clearInterval` | 高精度计时器驱动与销毁释放 |
| **媒体组件** | 微信原生 `<video>` 组件 | 支持手势操作、16:9 比例自适应内嵌播放 |

## 🔧 如何在本地运行与预览

1. **克隆/下载项目**：将代码包导入本地。
2. **打开微信开发者工具**：
   - 选择“导入项目”，目录定位到包含 `app.json` 的 `miniprogram` 文件夹。
   - AppID 可使用你的个人测试号。
3. **环境配置**：
   - 确保微信开发者工具中勾选了 **“详情 -> 本地设置 -> 启用 TypeScript 编译插件”**。
   - 基础库建议选择 `3.0.0` 或以上版本以获得最佳的 `glass-easel` 渲染性能。
4. **真机预览**：点击工具栏的“预览”生成二维码，使用手机微信扫码，即可在真机上体验爽快的重震动盲操反馈。
