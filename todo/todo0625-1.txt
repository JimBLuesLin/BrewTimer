# 角色设定
你是一个经验丰富的高级微信小程序开发者，精通原生 WXML, WXSS, 和 JavaScript 开发。请帮我从零起草一个微信小程序，作为一个“私人咖啡冲煮计时器”。

# 核心需求概述
该小程序主要包含一个单页面应用（首页），分为两个主要视图状态：“参数配置视图”和“冲煮计时视图”。
用户在配置好参数后，点击开始，进入带有分段水量提醒的计时模式。

# 数据与逻辑规则（严格遵循）
1. 冲煮方式 (Method)：【手冲、冷萃】
2. 咖啡品种 (Beans)：【埃塞俄比亚、肯尼亚、哥伦比亚、危地马拉、曼特宁、拼配、其他】（仅作记录）
3. 烘焙程度 (Roast)：【浅度、中度、深度】
4. 研磨度 (Grind)：【极细、细、中、粗、极粗】
5. 咖啡粉量 (Weight)：输入框，默认 15g，可手动修改。

## 自动计算规则（联动响应）
当用户修改了“冲煮方式”、“烘焙程度”或“粉量”时，需要自动计算并更新以下字段：
- 【冷萃】：默认温度 5°C，粉水比 1:12。
- 【手冲-浅度】：默认温度 93°C，粉水比 1:16。
- 【手冲-中度】：默认温度 90°C，粉水比 1:15。
- 【手冲-深度】：默认温度 85°C，粉水比 1:14。
- 总水量 = 粉量 * 粉水比。

## 注水手法与分段提醒 (Pour Styles)
提供【三段式、一刀流、十段法】供选择。在“冲煮计时视图”中，根据选择的手法和当前时间，动态高亮显示当前需要注入的目标水量（Target Water）。以 15g 粉、1:15（总水量 225g）为例的计算逻辑如下，请写成根据总水量 (T) 和 粉量 (W) 动态计算的函数：

1. 三段式：
   - 阶段 1 (0s-30s)：焖蒸，目标注水量为 W * 2。
   - 阶段 2 (30s-1m10s)：目标注水量为 T * 0.6。
   - 阶段 3 (1m10s-结束)：目标注水量为 T。

2. 一刀流：
   - 阶段 1 (0s-30s)：焖蒸，目标注水量为 W * 2。
   - 阶段 2 (30s-结束)：中心缓慢注水，目标注水量为 T。

3. 十段法 (极端分段示例，均匀注入)：
   - 包含焖蒸在内共分为 10 段，每段间隔 20 秒，每段目标水量递增 T / 10。

# 文件与代码生成要求
请直接生成或修改以下文件内容，确保代码可以直接在微信开发者工具中运行：

1. `app.json`：基础配置，设置合适的导航栏颜色（建议咖啡色调 #4A3018）和标题“咖啡冲煮助手”。
2. `pages/index/index.wxml`：
   - 顶部：参数配置区（使用 picker 和 input，布局美观清晰）。
   - 中部：自动计算结果展示（展示计算出的水温、粉水比、总水量）。
   - 底部操作区：开始冲煮按钮。
   - 切换状态：点击开始后，隐藏配置区，显示大号居中的“计时器”组件和“当前阶段指示器（包含时间范围、当前应注水至多少克、操作提示）”，以及“结束冲煮”按钮。
3. `pages/index/index.wxss`：
   - 使用 Flex 布局。
   - UI 风格采用现代极简的卡片式设计，主色调使用咖啡色系（如 #6F4E37, #F5F5DC 等）。
   - 计时器字体需要足够大且醒目。
4. `pages/index/index.js`：
   - 实现所有的联动响应计算（水温、比例、总水量）。
   - 实现 `setInterval` 计时器逻辑（格式化为 mm:ss）。
   - 实现根据当前秒数推演阶段的逻辑，当进入新阶段时，调用 `wx.vibrateShort()` 震动提醒用户。
   - 在开始冲煮时调用 `wx.setKeepScreenOn({ keepScreenOn: true })` 保持屏幕常亮。

请开始编写完整的代码。
